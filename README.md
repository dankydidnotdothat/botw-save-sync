# BOTW Save Sync (PC Cemu ↔ Nintendo Switch)

Комплект из двух программ для автоматической синхронизации и конвертации сохранений *The Legend of Zelda: Breath of the Wild* между ПК (Cemu) и прошитой Nintendo Switch:

-  — десктопная программа с графическим интерфейсом на Python (конвертация Wii U ↔ Switch, автобэкап, синхронизация по Wi-Fi через FTP или через локальную папку).
-  — homebrew-приложение  для Switch на  (экспорт/импорт сохранения BOTW одной кнопкой и страховочный автобэкап).

## Как получить готовый 
После загрузки файлов в репозиторий откройте вкладку **Actions** → **Build BOTWSaveSync.nro** и скачайте готовый файл из раздела **Artifacts**. Скопируйте его на SD-карту консоли по пути .

## Как запустить программу на ПК

Дополнительные библиотеки не требуются (используется только стандартная библиотека Python 3).
